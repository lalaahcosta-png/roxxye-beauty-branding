# 💄 Roxxye Beauty - Curadoria e Branding

A **Roxxye Beauty** é uma operação de e-commerce focada em curadoria estratégica de produtos de beleza e maquiagem. O projeto une visão de mercado, design de marca e gestão de vendas digitais.

## 📋 Modelo de Negócio
*   **Curadoria de Produtos:** Seleção estratégica de itens de beleza de marcas parceiras com base em tendências de mercado.
*   **Gestão de E-commerce:** Implementação de loja virtual utilizando modelos de logística inteligente.
*   **Branding:** Desenvolvimento completo da comunicação visual e posicionamento da loja.

## 🛠️ Competências Aplicadas
*   **Gestão Administrativa:** Controle de processos e planejamento do negócio.
*   **Marketing Digital:** Curadoria de catálogo e identidade visual.
*   **Tecnologia:** Configuração de plataforma de vendas e ferramentas de gestão.
